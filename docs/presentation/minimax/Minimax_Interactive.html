How to read the search
Coordinates are (row, column), starting at zero. O moves down; X moves up. All six pieces in this example are ordinary pieces.
Score = O’s material − X’s material. An ordinary piece is worth 3; a king would be worth 6. Positive is good for the BOT.
Depth 3: first simulate the BOT’s candidate move, then a human response, then a BOT response. At depth 0, evaluate the resulting board.
Every child uses new Game(game). Alternative moves start from the same parent position. Scores are compared with MAX/MIN; they are not added along a path.
